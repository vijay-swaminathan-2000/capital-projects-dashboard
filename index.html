Every reporting cycle, the incoming progress reports arrive with inconsistent time units (hours/minutes/day-fractions), mixed date formats, near-duplicate entries, and occasional out-of-range values. Before data reaches a dashboard, it's parsed into standard units, deduplicated against existing records, and range-checked — with anything outside plausible bounds flagged for review rather than silently accepted.

Data Sources & Metric Lineage

Where every number on this page comes from

Four source files feed this dashboard. Each card below names the dataset, the team who owns it, how often it lands, and when it last ran — because a KPI is only as current as its slowest input. The ⓘ marker beside any tile, chart or card on this page opens its definition; Trace to source inside that popover opens the full lineage — the calculation with today's numbers, the raw fields behind it, and what the metric does not tell you.

Every metric is defined once, in one registry, and the tiles, charts, status colours, tooltips and this table all render from it. A definition cannot drift from the number it describes, because they are the same object.

About this project. This is a self-contained portfolio demo built to show dashboard reporting, KPI design, and data-cleaning conventions used in project controls — not a production system. All project data is synthetic. Built with hand-rolled SVG charts (no charting library) in a single HTML/CSS/JS file, styled to a validated accessible color system (colorblind-safe categorical palette, status colors always paired with a label, table-view fallback for every chart). The AI narrative panel is live-capable: click "Use live Claude API" under any project's narrative and paste an Anthropic API key to have Claude generate the executive summary from that project's real KPI data. The key is stored only in your browser's localStorage — it is never written to this file, never committed to version control, and is sent only to api.anthropic.com. Without a key, the panel shows a pre-written example so the dashboard works for anyone browsing the portfolio.
